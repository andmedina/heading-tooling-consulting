# Heading & Tooling marketing website

Static marketing website for heading machine support, tooling review, and production analytics.

Live site: https://andmedina.github.io/heading-tooling-consulting/

## Pages

- `index.html`: services, approach, illustrative scenario, anonymous expertise, FAQs, on-page inquiry review, and sharing.
- `heading-support.html`: machine support details and an illustrative review sequence.
- `tooling-review.html`: tooling review details and an illustrative review sequence.
- `data-analytics.html`: service details and a fictional dashboard with downtime, rejection, and output views.
- `assets/site.css`: shared responsive styling.
- `assets/share-card.png`: social link preview image; editable SVG source is included.

## Behavior

The inquiry form and its personal-data fields remain available. It only displays an on-page review; it sends nothing to a server and generates no files. The dashboard uses fixed fictional values and has no data connection. There is no database, analytics tracker, or submission endpoint. Fonts are loaded from Google Fonts. Copy-link uses the browser clipboard and offers a visible URL if unavailable.

## Preview and publishing

Open `index.html` in a browser, or serve this folder with a local static web server. GitHub Pages publishes the repository root from `main`.

Business branding remains subject to owner review. No personal team names, client testimonials, certifications, service-area claims, or achieved performance results are published. The public copy is presented as a finished marketing site for internal team review. The dashboard values are synthetic; they do not represent client results. Inquiry review and editing stay local and do not claim that a message was delivered. Connect a real submission service before offering message delivery.
